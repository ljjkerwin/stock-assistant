# 小红书暗盘回复助手

Chrome / Edge Manifest V3 扩展。在小红书「通知」页打开一条评论的回复框后，插件会以不占文档流的浮层在输入框下方显示「查找明暗盘数据」按钮；它只写入草稿，绝不自动发送。

## 安装与配置

1. 启动本项目后端（默认 `http://localhost:3100`），并在 `backend/.env` 配置 `SILICONFLOW_API_KEY`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用「开发者模式」，选择「加载已解压的扩展程序」，目录选择本目录。
3. 在股票助手「管理中心」的「浏览器插件访问令牌」模块新建一个令牌并复制；它以 `xhs_` 开头且只显示一次。
4. 点击浏览器工具栏中的扩展图标，选择服务环境并填写上述插件访问令牌。默认生产环境为 `https://stock.vdata.top/api`；本机调试时切换为开发环境 `http://localhost:3100/api`。
5. 打开小红书通知页，点击任意「回复」，选择收盘日期后点击功能按钮。

## 使用边界

- 插件将当前通知项中的文字交给本地股票助手后端提取股票名称，不直接调用模型服务，也不暴露模型密钥。
- 日期默认为当天；历史评论可手动调整。该接口仅返回已归档的 15:00 收盘数据。
- 小红书页面结构可能调整。若按钮没有出现，刷新通知页后重试；若仍无法恢复，需要更新 `content.js` 的回复框定位规则。

## 权限

扩展仅申请小红书通知页、本机 `localhost:3100` / `127.0.0.1:3100` 后端地址和扩展设置存储权限。若后端部署在其他域名或端口，需要在 `manifest.json` 的 `host_permissions` 中显式增加该地址后重新加载扩展。
